# Custom Made Canvas Canopies

Website for Custom Made Canvas Canopies, Pretoria: canvas canopies, aluminium and steel cattle rails, hunting rails, roof racks with built-in long-range tanks, rooftop tents, canvas covers, awnings and shadenets.

Live: https://obsidianstudiodesigns.github.io/Custom-Made-Canvas-Canopies/

- Static HTML, CSS and JavaScript with no build step, hosted on GitHub Pages.
- Work photos come from the business's Facebook page. The hero, mobile hero and workshop images are AI-generated scene-setters.
- `tools/build_assets.py` makes the WebP images, favicons and the WhatsApp/social share image (`assets/img/og-share.jpg`) from the raw files in `_source/` (not in git).
- `tools/build_pages.py` makes the privacy policy, terms, 404, robots.txt, sitemap.xml and the manifest.
- `tools/build_icons.py` packs the Phosphor icons into `assets/icons.svg`.
- The quote form has no backend: it opens WhatsApp to 082 950 8390 with the message filled in.

## To confirm with the client

- Opening hours (Facebook says "Always open", so hours are left off the site).
- That the man in the long-range tank photo is happy to be shown.
- Quote validity (terms default to 14 days if a quote does not say).
- Whether they want a custom domain.
